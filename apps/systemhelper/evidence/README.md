# SystemHelper Static Evidence

These selected files from the existing apktool output retain their original bytes and text line numbers. See the [evidence index](../evidence-index.json) for hashes. The publication includes a subset of OEM collectors and excludes the complete APK, runtime logs, and the full REA session record.

Report references use physical file line numbers. The smali `.line` directives refer to debug metadata. The code shows field names, APIs, and built-in vendor constants. Actual values read from the source device stay local. Use the [final report](../REPORT.md) to interpret the evidence. The review did not repeat every coverage claim in the historical report and tool documentation.
