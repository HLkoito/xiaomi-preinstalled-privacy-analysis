# 公开资料的隐私处理

## 发布边界

公开包包含应用样本信息、脱敏报告、精选静态代码证据、分析工具及文件摘要。来源设备的身份及运行记录保存在本地。

处理范围：

- 清除本地用户名、用户目录、个人账号、会话/聊天标识及与来源用户关联的路径。
- 排除 ADB 原始输出、手机安装清单、权限访问历史、使用记录、调度器日志和原始聊天导出。
- 排除真实设备序号、IMEI/IMSI/ICCID/手机号、网络名称、路由器地址、个人 IP、定位坐标和令牌值。
- 文件名、文本内容及 Git 提交作者信息分别检查；发布从新的 Git 历史开始，使用中性研究作者。
- 对用户指定的禁用标识进行大小写不敏感扫描，并检查 URL 解码、Unicode 规范化后的文本。

## 保留的信息

应用包名、版本、SHA-256、厂商业务域名、API 字段名、公开证书标识、源代码内置的 SDK 服务地址和算法常量用于识别样本及复核代码。这些信息描述的是软件样本。

报告中 `IMEI`、`SSID`、`OAID` 等词是采集字段的名称。它们与个人设备实际取值分别处理。

## 检查方式

发布前人工检查选入文件及机器扫描候选值；用 `tools/privacy-check.mjs` 检查用户路径、会话标识、常见凭据与被禁止的文本标识。文件 SHA-256 写入 `ARTIFACTS.json`，可用 `tools/verify-integrity.mjs` 复算。

隐私扫描为基于规则的检查，报告中的“通过”指已列规则及选入文件的人工审阅结果。后续修改可继续使用同一工具复核。
