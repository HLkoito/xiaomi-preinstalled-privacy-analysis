## Key differences when interpreting these data flows

- The usage record source for SystemHelper is UsageStats; the above inventory sources for GuardProvider and Security Center are non-system app enumerations. The coverage of the two types of lists differs.
- Key names such as `imei` need to be traced to the assignment point: this field in the security center traffic query uses the Android ID derived value; OneTrack's identification list goes through MD5.
- Request body encryption and transport layer protection are two-layer processing. SystemHelper uses HTTP after AES processes JSON; the model/manufacturer and other metadata in URL are located in the request parameters.
- Some reports have clear business confirmation steps. The upload confirmation of calibration SMS, earthquake volunteer joining process and alarm auxiliary switch are part of the analysis of the corresponding data stream.
- FBO The path named `upLoadPackageList()` is written to the local machine `Settings.Secure` and handed over to the system service, which should be classified as local data transfer.
